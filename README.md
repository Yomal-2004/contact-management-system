# Contact Management System

A simple desktop-based Contact Management System built with **Python and Tkinter**. The application allows users to manage contact information through a graphical user interface, with SQLite database storage for persistent data management.

## Features

- **Add Contacts** — Save names, phone numbers, and email addresses.
- **View Contacts** — Display saved contact records.
- **Search Contacts** — Find contacts by name, phone number, or email.
- **Update Contacts** — Edit existing contact information.
- **Delete Contacts** — Remove unwanted contact records.
- **Persistent Storage** — Store and retrieve contacts using SQLite.

## Technologies Used

- **Python** — Application logic and functionality
- **Tkinter** — Graphical user interface (GUI)
- **SQLite** — Database for storing contact information

## Project Structure

```text
contact-management-system/
├── main.py       # Main application and GUI
├── database.py   # Database operations
└── contacts.db   # SQLite database (created automatically)
```

## Getting Started

### Prerequisites

- Python 3.x
- A code editor such as Visual Studio Code

Tkinter and SQLite are included with many standard Python installations. No additional database server is required.

### Installation

1. Clone this repository:

   ```bash
   git clone Yomal-2004/contact-management-system
   ```

2. Navigate to the project directory:

   ```bash
   cd contact-management-system
   ```

3. Run the application:

   ```bash
   python main.py
   ```

The SQLite database and required table are created automatically when the application starts.
